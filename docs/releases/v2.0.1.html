Sotto 2.0.1

Soft Wave app and menu bar icons, a consistent menu popover, and refined capsule, dot, and floating recording controls.

The capsule and floating window now use the display containing the focused writing window when Accessibility can identify it.

Whisper Large v3 Turbo remains the local speech engine. Optional Parakeet, Cohere, and Qwen app support has been removed. Existing downloaded optional model files are not deleted automatically.

For Apple silicon Macs running macOS 14 or later. This self-signed app is not notarized; Control-click and choose Open on first launch.
