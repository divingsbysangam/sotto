# Sotto 2.0.1

This update brings the Soft Wave app icon and a faint glass menu bar mark, a more consistent menu popover, and refined capsule, dot, and floating recording controls. The capsule and floating window now appear on the display containing the focused writing window when Accessibility can identify it.

Whisper Large v3 Turbo remains the local speech engine. The optional Parakeet, Cohere, and Qwen model choices and their app support have been removed. Existing downloaded optional model files are not deleted automatically.

Sotto runs on Apple silicon Macs with macOS 14 or later. It is self-signed and not notarized. On first launch, Control-click **Sotto.app**, choose **Open**, then confirm **Open**.
